# JOGOS PARA VENDA

Portfólio de jogos desenvolvidos para comercialização. Cada jogo fica em sua própria pasta, com código, documentação (estudo de mercado, GDD, financeiro) e testes.

| Jogo | Pasta | Status |
|---|---|---|
| **PRISMORA** — roguelite de puzzle de luz | `prismora/` | Protótipo jogável (v0.1), sem playtest com jogadores reais |

Para jogar o Prismora: abra a pasta `prismora/` e siga o `README.md` de lá (`python3 -m http.server 8765`).
